# متن Rmz 2 برای Premiere Pro

این بسته از سورس موجود در ZIP کاربر ساخته شده و شناسه‌ی جداگانه دارد؛ بنابراین می‌تواند کنار نسخه‌ی فعلی نصب شود. در این نسخه هیچ وابستگی به Lovable یا سرویس‌های Manus وجود ندارد. دکمه‌ی «بروزرسانی» نسخه و فایل‌ها را از مخزن اختصاصی GitHub می‌خواند.

## قابلیت‌های موجود در این ZIP

- واردکردن فایل‌های زیرنویس SRT و VTT به‌صورت آفلاین و ساخت گرافیک‌های متنی روی تایم‌لاین.
- ابزارهای طراحی متن، فونت، رنگ، افکت و موشن که در سورس ZIP موجود بوده‌اند.

این ZIP شامل موتور Whisper، فایل مدل یا WASM برای تبدیل خودکار صدا به زیرنویس نیست؛ بنابراین قابلیت تبدیل گفتار به زیرنویس خودکار در این نسخه وجود ندارد.

## بروزرسانی خودکار

آدرس updater در `js/main.js` به مخزن جداگانه‌ی `pooryaabbasi1/textstudio-rmz-2` تنظیم شده است. برای اینکه Premiere بدون ورود به GitHub بتواند فایل‌ها را از Raw دریافت کند، مخزن باید عمومی باشد. با هر انتشار جدید باید فایل `version.json` را با شماره‌ی نسخه‌ی جدید و فهرست فایل‌های تغییرکرده به‌روز کرد و commit را روی شاخه‌ی `main` قرار داد. افزونه در اجرای بعدی دکمه‌ی بروزرسانی را از همین مخزن می‌خواند.

## نصب در Windows

1. پوشه‌ی `TextStudio-Rmz-2` را در مسیر `%AppData%\Adobe\CEP\extensions\` کپی کنید. اگر پوشه وجود ندارد، آن را بسازید.
2. Premiere Pro را کامل ببندید و دوباره اجرا کنید.
3. از مسیر `Window > Extensions (Legacy) > متن Rmz 2` پنل را باز کنید.
4. نسخه‌ی اصلی با شناسه‌ی `com.poorya.textstudio.panel` دست‌نخورده می‌ماند. شناسه‌ی این نسخه `com.poorya.textstudio.v2.panel` است.

اگر Premiere به‌دلیل unsigned بودن افزونه آن را نمایش نداد، باید حالت بارگذاری CEP افزونه‌های توسعه‌ای را در تنظیمات سیستم فعال کنید؛ پس از نصب مجدد، مقدار debug به شناسه‌ی نسخه 2 و پورت 8089 اشاره می‌کند.
