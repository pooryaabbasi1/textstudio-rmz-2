# متن Rmz 2 برای Premiere Pro

این افزونه از سورس تازه‌ای که کاربر ارائه کرده ساخته شده و شناسه‌ی مستقل خود را حفظ می‌کند؛ بنابراین می‌تواند در کنار نسخه‌ی قبلی نصب شود. نام افزونه «متن Rmz 2» و شناسه‌ی آن `com.poorya.textstudio.v2.panel` است. دریافت به‌روزرسانی فقط از مخزن عمومی GitHub همین نسخه انجام می‌شود و افزونه برای اجرا به Lovable وابسته نیست.

## قابلیت‌ها

- ساخت و واردکردن زیرنویس SRT و VTT و افزودن متن و موشن به تایم‌لاین Premiere Pro.
- ابزارهای طراحی متن، فونت، رنگ، افکت، موشن و افکت تصویر موجود در سورس جدید.
- تبدیل گفتار به زیرنویس با مدل Whisper، شامل انتخاب کلیپ صدا/ویدیو در Premiere یا انتخاب فایل صوتی/ویدیویی.

### مدل Whisper و حالت آفلاین

وزن‌های مدل در بسته‌ی نصب به پنج قطعه تقسیم شده‌اند تا میزبانی‌شان در GitHub ممکن باشد. هنگام نخستین اجرای تشخیص گفتار، افزونه قطعات را در پوشه‌ی خودش به فایل‌های ONNX کامل تبدیل می‌کند و قطعات موقت را پاک می‌کند. پس از آماده‌شدن مدل، تشخیص گفتار به اینترنت یا سرویس Lovable نیاز ندارد. برای آماده‌سازی نخستین‌بار، افزونه به حدود 150 مگابایت فضای موقت نیاز دارد؛ حجم نصب‌شده پس از پاک‌شدن قطعات تقریباً 80 مگابایت است.

## به‌روزرسانی

دکمه‌ی «بروزرسانی» نسخه و فایل‌های لازم را از [مخزن عمومی `pooryaabbasi1/textstudio-rmz-2`](https://github.com/pooryaabbasi1/textstudio-rmz-2) از راه GitHub Raw می‌خواند. نسخه‌ی `2.1.0` شامل فایل‌های کامل برنامه و قطعات مدل است. برای انتشار نسخه‌های بعدی، نسخه و فهرست فایل‌های تغییرکرده را در `version.json` به‌روزرسانی و تغییرات را روی شاخه‌ی `main` منتشر کنید؛ فایل `.debug` جزو فایل‌های updater نیست.

## نصب در Windows

1. ZIP را استخراج کنید.
2. پوشه‌ی `TextStudio-Rmz-2` را در `%AppData%\Adobe\CEP\extensions\` کپی کنید. اگر پوشه‌ی `extensions` وجود ندارد، آن را بسازید.
3. Premiere Pro را کاملاً ببندید و دوباره اجرا کنید.
4. از مسیر `Window > Extensions (Legacy) > متن Rmz 2` پنل را باز کنید.

شناسه‌ی این نسخه `com.poorya.textstudio.v2.panel` است و با شناسه‌ی افزونه‌ی اصلی `com.poorya.textstudio.panel` فرق دارد. اگر Premiere به‌دلیل unsigned بودن افزونه آن را نمایش نداد، بارگذاری افزونه‌های CEP توسعه‌ای را در سیستم فعال کنید؛ فایل `.debug` برای شناسه‌ی نسخه‌ی 2 و پورت 8089 تنظیم شده است.

## عیب‌یابی

- برای نخستین تشخیص گفتار، صبر کنید تا مدل محلی آماده شود؛ اجرا ممکن است به‌دلیل اندازه‌ی مدل کمی طول بکشد.
- اگر پیام کمبود فضا یا فایل مدل ناقص دیدید، پوشه‌ی `models/whisper-base/onnx/` را بررسی کنید و نصب را دوباره از ZIP کامل انجام دهید.
- تست نهایی عملکرد و ASR باید داخل Premiere Pro انجام شود؛ پیش‌نمایش مرورگر جای تست CEP را نمی‌گیرد.
